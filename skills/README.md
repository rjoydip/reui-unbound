# Project Skills

Skills for agents working on reui-unbound. Each directory follows the
[Agent Skills specification](https://agentskills.io/specification) and can be
installed with `npx skills add <owner>/reui-unbound`.

| Skill | Use when |
| --- | --- |
| [`data-grid-block`](./data-grid-block/SKILL.md) | Adding or changing a demo block |
| [`registry`](./registry/SKILL.md) | Registry items, manifests, dependencies, verification |
| [`component-flavors`](./component-flavors/SKILL.md) | Base/Radix ReUI components and shared modules |
| [`bun-cloudflare`](./bun-cloudflare/SKILL.md) | Bun runtime, CI and Cloudflare deployment |

Skills load on demand. Read `SKILL.md` before starting matched work.
