# Autocomplete

Searchable input with async suggestions and keyboard navigation.

## Preview

- **Radix** — [`autocomplete-radix`](https://reui-unbound.pages.dev/?preview=autocomplete-radix)
- **Base** — [`autocomplete-base`](https://reui-unbound.pages.dev/?preview=autocomplete-base)

## Install

```bash
# Radix
bunx --bun shadcn@latest add @reui-unbound/autocomplete
```

```bash
# Base
bunx --bun shadcn@latest add @reui-unbound/base-autocomplete
```
