# Data Grid

Composable table with sorting, selection, pagination and virtualization.

## Preview

- **Radix** — [`data-grid-radix`](https://reui-unbound.pages.dev/?preview=data-grid-radix)
- **Base** — [`data-grid-base`](https://reui-unbound.pages.dev/?preview=data-grid-base)

## Install

```bash
# Radix
bunx --bun shadcn@latest add @reui-unbound/data-grid
```

```bash
# Base
bunx --bun shadcn@latest add @reui-unbound/base-data-grid
```
