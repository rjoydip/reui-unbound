# Badge

Compact status labels with light, outline and solid variants.

## Preview

- **Radix** — [`badge-radix`](https://reui-unbound.pages.dev/?preview=badge-radix)
- **Base** — [`badge-base`](https://reui-unbound.pages.dev/?preview=badge-base)

## Install

```bash
# Radix
bunx --bun shadcn@latest add @reui-unbound/badge
```

```bash
# Base
bunx --bun shadcn@latest add @reui-unbound/base-badge
```
