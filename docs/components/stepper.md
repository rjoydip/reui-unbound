# Stepper

Multi-step navigation with indicators and panels.

## Preview

- **Radix** — [`stepper-radix`](https://reui-unbound.pages.dev/?preview=stepper-radix)
- **Base** — [`stepper-base`](https://reui-unbound.pages.dev/?preview=stepper-base)

## Install

```bash
# Radix
bunx --bun shadcn@latest add @reui-unbound/stepper
```

```bash
# Base
bunx --bun shadcn@latest add @reui-unbound/base-stepper
```
